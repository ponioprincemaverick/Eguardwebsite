An ECE technopreneurship project from Pangasinan, built for school labs and hobby benches.

Four readings. One alert when it matters.

Set the safe range for each piece of equipment once. E-Guard keeps watching, so a fault gets caught while it is still a warning and not a burnt board.

  • Voltage

    Catches sags and surges on the supply line before they reach sensitive circuits and instruments.

    Example: alert below 200 V or above 240 V

  • Current

    Flags overcurrent from short circuits, wrong wiring, or equipment drawing more than it should.

    Example: alert above 5.0 A

  • Temperature

    Tracks heat build-up in power supplies, motors, and soldering stations during long sessions.

    Example: alert above 60 °C

  • Equipment status

    Shows at a glance whether the connected equipment is off, running normally, or in a fault state.

Set up in minutes.

No programming needed. If you can wire a bench supply, you can install E-Guard.

  1. Connect

    Run the equipment's power through E-Guard and place the temperature sensor near it.

  2. Set limits

    Choose the safe voltage, current, and temperature range for that equipment.

  3. Monitor

    E-Guard reads every value continuously and shows the live status on its display.

  4. Get alerted

    The moment a reading leaves its safe range, E-Guard alerts you so you can switch off in time.
